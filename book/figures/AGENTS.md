# AGENTS.md — `figures/`

## Directory Overview

The `figures/` directory stores static branding and icon assets (favicon and vector logos) referenced by `book/_config.yml` for the TeachBooks book website header and browser tab icon.

## Subdirectories

None.

## Files in Current Directory

- **`TB_favicon.ico`**: Multi-resolution Windows icon file (`.ico` with 6 embedded icon sizes up to 256×256 RGBA PNG) used as the browser favicon (`html.favicon` in `_config.yml`).
- **`TeachBooks_logo.svg`**: Scalable Vector Graphics (`1080×1080` `viewBox`) TeachBooks logo featuring the stylized TeachBooks book/brain graphic and wordmark, configured as the default site logo (`logo` in `_config.yml`).
- **`TeachBooks_logo_inverted.svg`**: Inverted/dark-mode Scalable Vector Graphics (`1080×1080` `viewBox`) variant of the TeachBooks logo and wordmark for dark/light theme adaptation.
