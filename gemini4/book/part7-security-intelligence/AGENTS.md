# AGENTS.md — `book/part7-security-intelligence`

## Directory Overview

This directory contains **Part VII: Cybersecurity, Spoofing, National Security & Alternative Tracking** of *AIS: The Open Manual*. It covers the foundational security flaws and non-malicious hardware/sensor failure modes of AIS, physical-layer Specific Emitter Identification (SEI / RF fingerprinting) and spoofing detection, naval Operations Security (OPSEC), Encrypted AIS (EAIS / NATO W-AIS), dark-vessel detection with Global Fishing Watch and spaceborne Synthetic Aperture Radar (SAR), alternative tracking via mobile phone cellular attachment and `SS7`/`Diameter` core signaling exploits, physical commodity trading on the Bloomberg Terminal, and dynamic North Atlantic Right Whale conservation via **Listen for Whales** and **Whale Alert**.
