## Directory Overview
This leaf directory contains Part VIII ("Bit-Level Message Deep Dives, NMEA 2000 Mapping, and Application-Specific Messages") of *AIS: An Open Manual* (`ch31` through `ch40`). It provides exhaustive, bit-by-bit protocol references, two's-complement/scaling equations, NMEA 0183 (`!AIVDM`) to NMEA 2000 (`PGN`) and Signal K translations, real-world hardware quirks, security failure modes, Python reference parsers, and multi-library support tables for all 27 ITU-R M.1371 message types as well as International (`DAC = 1`) and Regional (`DAC = 200, 232, 235, 316, 366, 351, 370, 503, 440`) Application-Specific Messages (ASMs).

### 4. `ch34-messages-09-18-19-27-sar-class-b-long-range.md`
- **Title:** Chapter 34: Messages 9, 18, 19, and 27 — SAR Aircraft, Class B Position Reports, and Long-Range S-AIS
- **Summary:**
  - **Four Specialized Position Reports:** Examines the architectural trade-offs and bit layouts of `Msg 9` (`168b` SAR Aircraft), `Msg 18` (`168b` Standard Class B Position Report), `Msg 19` (`312b` Extended Class B Position + Static Report), and `Msg 27` (`96b` Long-Range S-AIS Broadcast).
  - **Critical Bit-Level Differences & Parser Traps:**
    - `Msg 9` (`Ais9`, `111MIDxxx`): Replaces `NavStatus` + `ROT` with a 12-bit `Altitude` (`bits[38:50]`, `0–4094 m`, `4095` = N/A, `4094` = $\ge 4094\text{ m}$), scales `SOG` (`bits[50:60]`) in **whole knots** (`0–1022 kt`, $10\times$ Msg 1!), uses `bit[137]` as `Altitude Sensor` (`0` = GNSS, `1` = barometric), and switches between SOTDMA (Mode A, `bit[148]=0`) and ITDMA (Mode B, `bit[148]=1`).
    - `Msg 18` (`Ais18`): Omits `NavStatus` and `ROT`, shifting `SOG`, `Position Accuracy`, `Longitude`, `Latitude`, `COG`, `True Heading`, and `Time Stamp` **4 bits earlier (`bits[46:139]` instead of `bits[50:143]`)**—a classic copy-paste bug that scrambles Class B coordinates. Replaces manoeuvre flags with 6 Class B capability flags (`CS Unit`, `Display`, `DSC`, `Band`, `Msg 22`, `Assigned`) and emits a constant `1100000000000000110` (`0x60006` / `0x349B0` with `CommStateSelector=1`) in `bits[149:168]` for Class B "CS".
    - `Msg 19` (`Ais19`, `312 bits`): Appends `Name`, `Ship Type`, `Dimensions A–D`, `EPFD`, `RAIM`, and `DTE` to `Msg 18`; explains why ITU-R M.1371-3 deprecated autonomous `Msg 19` broadcasts in favor of `Msg 24A/B` due to Slot $k+1$ hidden-terminal collisions.
    - `Msg 27` (`Ais27`, `96 bits` on Ch 75/76 `156.775/156.825 MHz`): Uses `Repeat = 3` (do not retransmit), $1/10\text{ min}$ ($185.2\text{ m}$) 18/17-bit coordinates, 6-bit whole-knot `SOG` (`0–62 kt`), 9-bit whole-degree `COG`, a $10.83\text{ ms}$ guard buffer ($3,246\text{ km}$ LEO slant range), **inverts `GNSS Position Status` (`bit[94]`: `0` = current GNSS, `1` = not current!)**, and exhibits a 168-bit zero-padded firmware bug on older transponders.
  - **Dual-Resolution Kalman Filtering:** Implements a Python parser for all four messages plus a 4-state Constant-Velocity ENU Kalman Filter (`DualResolutionAisKalmanFilter`) with measurement covariance $\mathbf{R}_1 = \operatorname{diag}(5^2, 5^2)\text{ m}^2$ vs. $\mathbf{R}_{27} = \operatorname{diag}(53.5^2, 53.5^2)\text{ m}^2$ to eliminate $185.2\text{ m}$ sawtooth velocity spikes when fusing `Msg 1/18` and `Msg 27`.

  - **Binational St. Lawrence Seaway AIS (`DAC = 316` SLSMC Canada & `DAC = 366` GLS USA):** Explains how all 15 locks from Montreal to Lake Erie share an identical bit layout across `DAC = 316` and `DAC = 366` (requiring a single parser registered to both DACs) with a common 32-bit Seaway Header (`bits[56:88]`). Details all five Seaway messages:
    - `FI = 1` (`Weather Station / Wind`, up to 6 × 120-bit reports),
    - `FI = 2` (`Water Level / Current / Ballast / Hazmat`),
    - `FI = 32` (`Version 1` Process / **Lockage Order Queue**, `216–648b`, broadcasting up to 6 vessels in the lock queue with 90-bit 15-char truncated `Vessel Name`, `Direction`, and `Lockage Time`),
    - `FI = 33` (`Addressed Lockage Order / Tie-Up ETA`),
    - `FI = 34` (`Version 2 Water Level & Hydrological Flow`, up to 6 × 96-bit reports carrying `Water Level` in $0.01\text{ m}$ referenced to `datum_flag = 0` IGLD-85 vs. `1` Chart Datum, plus `Flow Rate` in $\text{m}^3/\text{s}$ to alert pilots to cross-channel weir surges).
  - **USCG Area Notice (`DAC = 366, FI = 22 / 23`) & NOAA PORTS®:** Chronicles the 2008 Stellwagen Bank *Listen for Whales* / *Whale Alert* origin of `DAC = 366, FI = 22` (`Ais8_366_22`, co-designed by Kurt Schwehr, NOAA, USCG, and Woods Hole), detailing the `93-bit` Pre-2010 legacy vs. `87-bit` harmonized sub-area bit length check (`(len(bits) - 111) % 87 == 0` vs. `% 93 == 0`) and the `Msg 6` `FI = 23` (IMO) vs. `FI = 22` (USCG) mismatch, alongside NOAA PORTS® / RTCM 12301.1 environmental broadcasts (`FI = 11, 26, 31`).
  - **USCG / DoD Encrypted AIS (`DAC = 366, FI = 56 / 57`, `Ais8_366_56`):** Dissects the 2-slot (`280–424 bit`) encrypted Blue Force Tracking envelope used by USCG `Command21`/`SeaWatch`/`Minotaur` and DoD `SeaVision`/`GCCS-M`: an outer `Msg 8` with a randomized `366999xxx`/`00366xxxx` MMSI + `Algorithm ID` + `Key ID` + `64-bit IV` + AES-256/Type-1 `Ciphertext` encapsulating a standard 168-bit `Msg 1` or `Msg 9` + `64/128-bit MAC`, and analyzes why Encrypted AIS hides coordinates/identity from OSINT while still exposing RF presence, AoA, TDOA, and SEI fingerprints on $161.975/162.025\text{ MHz}$.
  - **Global Regional ASMs, VDES / IHO S-100 Migration, & Master Support Matrix:** Surveys Panama Canal (`DAC = 351/370`), Australia Great Barrier Reef `REEFVTS` (`DAC = 503`), and South Korea (`DAC = 440`); maps legacy ASMs to VDES ASM (`Ch 2027/2028`), VDE-TER/SAT, and IHO S-100 (`S-104`, `S-111`, `S-124`, `S-212`, `S-421` signed under IEC 63173-2 SECOM); and provides the **3-part Definitive Master Software Support Matrix** comparing `libais`, `pyais`, `gpsd`, `AIS-catcher`, `ais-area-notice`, `Signal K`, `OpenCPN`, and `Wireshark` across all 27 ITU messages, all 27 `DAC = 1` FIs, and all 20 Regional ASMs, plus a complete Python parser for `DAC = 316/366` (`FI = 32, 34, 22, 56`).
