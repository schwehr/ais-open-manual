# Directory Summary: `book/part3-timing-protocol`

## Overview
`book/part3-timing-protocol` contains **Part III: Timing, GNSS, NMEA, and the AIS Protocol (Chapters 11–16)** of *The Open Manual of AIS*. This directory covers the physical-layer timing and slot synchronization architecture of AIS, multi-constellation GNSS and GNSS denial/jamming/spoofing behavior, the 30-bit MMSI and 7-digit IMO identity ecosystems, shipboard NMEA 0183 / NMEA 2000 / IEC 61162-450 LWE and Voyage Data Recorder (VDR) transport protocols, the complete bit-level catalog of ITU-R M.1371-5 Messages 1–27, and Binary Application-Specific Messages (ASMs) including NOAA PORTS® met/hydro broadcasts and Kurt Schwehr's `ais-area-notice` dynamic geographic geometries.

## Subdirectories
None (leaf directory).
