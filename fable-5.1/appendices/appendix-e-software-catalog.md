# Appendix E — Software catalog

This appendix catalogs the software ecosystem supporting the Automatic Identification System (AIS), ranging from physical-layer software-defined radio (SDR) demodulators and open-source bitstream decoders to spatial databases, trajectory analytics libraries, 3D kinematic animators, and enterprise Vessel Traffic Services (VTS) platforms.

The catalog reflects primary repository archaeology, package registry metrics (PyPI, crates.io, npm), and operational deployments documented across this handbook. It provides practitioners, software engineers, and researchers with an authoritative inventory of software tools, their implementation languages, licensing constraints, maintenance health (stamped as of October 2026), architectural capabilities, and cross-references to theoretical chapters in this handbook.

---

## E.1 Open-source protocol decoders and encoders

Decoders and encoders represent the foundation of the AIS software stack, translating between raw NMEA 0183 encapsulated payloads (`!AIVDM`/`!AIVDO`), binary VHF Data Link (VDL) bitstreams, and high-level typed data models. While decoding is a purely deterministic unpacking process, encoding requires precise bit-packing, reverse 6-bit ASCII mapping, CRC generation, and dynamic multi-sentence payload fragmentation ([Chapter 44](../chapters/ch44-open-source-decoders-history.md)).
