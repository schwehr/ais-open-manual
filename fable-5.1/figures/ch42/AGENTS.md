# `figures/ch42/`

Figure assets for Chapter 42 ("Home Receiver") of *The AIS Handbook*, an open,
citable handbook on the maritime Automatic Identification System. The chapter
walks a reader through building a low-cost shore-side AIS receiving station,
and this directory holds the single diagram it embeds: a block diagram of the
receiver signal chain from antenna to downstream consumers.

The SVG here is a *generated* artifact: it is produced by
`fig_home_receiver()` in [`code/figures/make_figures.py`](../../code/figures/make_figures.py)
(Matplotlib v3.11.2) and referenced from
[`chapters/ch42-home-receiver.md`](../../chapters/ch42-home-receiver.md) as
`![Low-budget home receiver signal chain](../figures/ch42/signal-chain.svg)`.

## Files

| File | Summary |
|---|---|
| `signal-chain.svg` | Matplotlib-rendered block diagram (460.8 × 161.7 pt, white background) titled "Low-budget home receiver signal chain". Eight rounded, light-blue boxes connected left-to-right by arrows, labelled: "162 MHz antenna" → "lightning arrestor" → "LMR-400 coax" → "FM notch / bandpass" → "LNA (optional)" → "RTL-SDR or dAISy" → "Raspberry Pi AIS-catcher" → "NMEA/UDP → OpenCPN, feeds". No axes or numeric data; purely a schematic. |

## Notes for agents

- **Do not hand-edit the SVG.** It is regenerated by running
  `code/figures/make_figures.py` (the `fig_home_receiver` function, which calls
  `save(fig, 42, "signal-chain")`). To change box labels, order, or styling,
  edit the `chain` list in that function and re-run the script; the output
  overwrites `figures/ch42/signal-chain.svg`.
- The figure's title text and the image alt text in
  `chapters/ch42-home-receiver.md` are both "Low-budget home receiver signal
  chain"; keep them in sync if either is changed.
- The SVG contains a `<dc:date>` metadata timestamp that changes on every
  regeneration, so expect spurious diffs in that line even when the drawing is
  unchanged.
- Sibling directories `figures/chNN/` follow the same pattern (one directory
  per chapter, SVGs produced by `make_figures.py`); the cookbook in
  `appendices/appendix-i-cookbook.md` shows the expected
  `wrote .../figures/ch42/signal-chain.svg` output from a run.
- There are no data files, scripts, or subdirectories here.
