# `figures/ch27/`

Rendered figures for Chapter 27 of "The AIS Handbook", an open, citable
handbook on the maritime Automatic Identification System. The two SVGs in
this directory illustrate VHF radio propagation at the AIS frequency
(162 MHz): how far a signal can reach over the curved Earth (radio horizon)
and how much signal is lost along the way (path loss).

Both files are Matplotlib-generated SVG plots (Matplotlib v3.11.2, dated
2026-10-04). They are build artifacts intended to be included by the
chapter text, not hand-drawn diagrams.

## Files

| File | Summary |
|---|---|
| `path-loss.svg` | Line plot titled "Path loss vs distance; dotted lines = 4/3-Earth radio horizon". X axis: distance (km), 0–120. Y axis: path loss (dB) at 162 MHz, 80–160. Curves: three two-ray ground-reflection models (h_tx=5 m/h_rx=30 m; h_tx=20 m/h_rx=50 m; h_tx=30 m/h_rx=200 m), each with a matching-colour vertical dotted line marking its 4/3-Earth radio horizon; a dashed black "free space" curve; and a horizontal red line labelled "12.5 W budget to −107 dBm (max loss)". |
| `radio-horizon.svg` | Line plot titled "d = 4.12(√h₁ + √h₂) km". X axis (log scale): receiver antenna height (m), 10⁰–10². Y axis: radio horizon (nmi), 0–50. Three curves for the horizon to a 2 m antenna (small craft), to a 20 m antenna (ship), and to sea level. |

## Notes for agents

- Both SVGs are generated by Matplotlib; do not hand-edit them. If the plot
  needs changing, regenerate it from the producing script (not located in
  this directory) and overwrite the SVG.
- The two figures are companions: `radio-horizon.svg` shows the geometric
  line-of-sight limit using the 4/3-Earth approximation
  `d = 4.12(√h₁ + √h₂) km`, and `path-loss.svg` marks that same 4/3-Earth
  horizon as dotted vertical lines on each two-ray path-loss curve.
- Units differ between the figures: `path-loss.svg` uses km on the X axis,
  `radio-horizon.svg` reports the horizon in nautical miles (nmi) with a
  logarithmic height axis.
- `path-loss.svg` uses "h_tx"/"h_rx" plain-text subscripts in its legend,
  while `radio-horizon.svg` uses Unicode "√h₁ + √h₂" in its title; keep any
  edited labels consistent with the chapter text.
- The red "12.5 W budget to −107 dBm (max loss)" line in `path-loss.svg`
  encodes a link-budget assumption (12.5 W transmit power, −107 dBm receiver
  threshold); if the chapter's link-budget numbers change, this figure must
  be regenerated to match.
- Renaming either file will break any chapter source that includes it by
  name; check for references before renaming.
