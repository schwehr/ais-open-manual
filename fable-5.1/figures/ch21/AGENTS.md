# `figures/ch21/`

Figure assets for Chapter 21 of *The AIS Handbook*, an open, citable handbook
on the maritime Automatic Identification System. This directory currently holds
a single Matplotlib-generated SVG that illustrates the SOTDMA (Self-Organized
Time Division Multiple Access) slot map used by AIS transceivers to share a VHF
channel.

The figure is referenced from the chapter text; it is a build artifact
(rendered with Matplotlib v3.11.2, dated 2026-10-04) rather than a hand-drawn
diagram.

## Files

| File | Summary |
|---|---|
| `slot-map.svg` | Matplotlib SVG (478.8 × 179.6 pt) titled **"SOTDMA slot map (one channel)"**. It draws a single row of 60 equal-width slot boxes, x-axis ticks at 0, 10, 20, …, 60, and the axis label *"slot number within the 1-minute frame (first 60 of 2,250; each 26.67 ms = 256 bits)"*. Most slots are light grey (`#eeeeee`); 13 are filled red (`#cc3333`) at slots 3, 5, 10, 16, 17, 24, 27, 31, 38, 45, 49, 52 and 59 to represent occupied slots. Two annotations with arrows: *"own nominal slot"* pointing down at slot 3, and *"next: +RI (e.g. 375 slots = 10 s), chosen within ±10 % selection interval"* pointing at the slot 16/17 boundary. There is no y-axis. |

## Notes for agents

- The SVG is machine-generated by Matplotlib; do not hand-edit the path data.
  If the figure needs to change, regenerate it from its source script (not
  located in this directory) and overwrite the file.
- All visible text lives in `<text>` elements near the end of the file
  (`text_1` … `text_11`); the slot rectangles are `patch_3` … `patch_62`
  (patch *N* corresponds to slot *N − 3*).
- Colors: `#eeeeee` = free slot, `#cc3333` = occupied slot. Keep this
  convention if adding sibling figures for the same chapter.
- Numeric facts embedded in the figure (2,250 slots per 1-minute frame,
  26.67 ms / 256 bits per slot, RI example of 375 slots = 10 s, ±10 % selection
  interval) should stay consistent with the Chapter 21 prose if either is
  edited.
- Only `slot-map.svg` and this `AGENTS.md` exist here; there are no
  subdirectories.
