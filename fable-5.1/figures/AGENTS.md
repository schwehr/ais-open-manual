# `figures/`

Rendered figure assets for "The AIS Handbook", an open, citable handbook on
the maritime Automatic Identification System. Each chapter that embeds a
diagram or plot has its own `figures/chNN/` subdirectory holding the SVG(s)
that the chapter's Markdown source references (e.g.
`![...](../figures/ch42/signal-chain.svg)` from `chapters/`).

Every SVG currently in this tree is a Matplotlib (v3.11.2) export produced by
`code/figures/make_figures.py` (the Chapter 30 saturation plot additionally
depends on the teaching simulator in `code/tdma/sotdma_sim.py`). The figures
are therefore derived build artifacts, not hand-drawn artwork; `LICENSES.md`
at this level records that they are original CC-BY-4.0 works and is the place
to register any imported third-party figure.

## Notes for agents
- **Do not hand-edit the SVGs.** Change the generating code in
  `code/figures/make_figures.py` (or `code/tdma/sotdma_sim.py` for ch30) and
  re-run it; the script writes `figures/chNN/<name>.svg` directly (the ch42
  function calls `save(fig, 42, "signal-chain")`). The cookbook in
  `appendices/appendix-i-cookbook.md` shows the expected `wrote .../figures/...`
  output of a run.
- Layout convention: one subdirectory per chapter, named `chNN` with a
  two-digit chapter number, containing only SVGs and an `AGENTS.md`. There are
  no PNG/PDF renders, data files or scripts in this tree; do not add binary
  renders unless the book build needs them.
- Filenames are referenced from chapter sources by name (relative path
  `../figures/chNN/<name>.svg` from `chapters/`); search for references before
  renaming or moving a figure. Keep figure titles and the Markdown alt text in
  sync.
- Every regeneration rewrites the `<dc:date>` metadata in each SVG, so expect
  one-line timestamp diffs even when the drawing is unchanged. All current
  files carry a 2026-10-04 date.
- Numeric facts baked into figures (161.975/162.025 MHz, 9.6 kbit/s GMSK,
  2,250 slots per minute, 256 bits/26.67 ms per slot, 12.5 W to −107 dBm link
  budget, footprint radii, etc.) must stay consistent with the chapter prose
  and with each other; a change in one place usually needs a regeneration here.
- Text in the SVGs is kept as `<text>` elements (DejaVu Sans, not outlined
  paths), so labels can be grepped and verified directly, and several files
  contain Unicode (−, ≈, √, subscripts); preserve UTF-8 when touching them.
- If a figure is imported rather than generated, add it to `LICENSES.md` with
  its source and licence; CC-BY-4.0 applies only to the `make_figures.py`
  outputs.
