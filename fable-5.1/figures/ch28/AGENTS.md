# `figures/ch28/`

Figures for Chapter 28 of "The AIS Handbook", an open, citable handbook on the
maritime Automatic Identification System. This directory currently holds a
single Matplotlib-generated SVG that illustrates the bit-level layout of one
AIS transmission packet (burst) within a 256-bit TDMA slot, as specified in
ITU-R M.1371 Annex 2.

The figure is a static asset intended to be referenced from the chapter's
manuscript; it contains no code or data.

| `burst-structure.svg` | Horizontal bar diagram titled "AIS transmission packet layout (ITU-R M.1371 Annex 2); bit stuffing may consume part of the buffer". The x-axis is labelled "bits (256 per slot at 9,600 bit/s = 26.67 ms)" with ticks 0–250. Seven labelled segments, left to right, with their bit counts: ramp-up (8), training 0101… (24), flag 7E (8), data (Msg 1: 168 bits) (168, shaded light blue; all other segments light grey), CRC-16 (16), flag 7E (8), buffer (24). Generated by Matplotlib v3.11.2 (dated 2026-10-04); 554×157 pt, no y-axis. |

## Notes for agents
- The segment bit counts sum to 256 (8+24+8+168+16+8+24), matching one AIS slot; keep this invariant if the figure is regenerated or edited.
- The SVG was produced by Matplotlib, not drawn by hand. The generating script is not in this directory; if you need to change the figure, look for a plotting script elsewhere in the repository (e.g. a `code/` or scripts directory) rather than hand-editing the SVG paths.
- Text labels are plain SVG `<text>` elements, so small wording fixes (e.g. the title or axis label) can be made directly in the SVG if the script cannot be located, but prefer regenerating.
- The data segment is sized for a Message 1 (position report, 168 bits); the title notes that bit stuffing may consume part of the 24-bit buffer.
- Do not add generated binaries (PNG/PDF) here unless the chapter build requires them; the SVG is the source asset.
