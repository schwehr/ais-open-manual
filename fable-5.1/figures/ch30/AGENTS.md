# `figures/ch30/`

Figure assets for Chapter 30 of "The AIS Handbook", an open, citable handbook
on the maritime Automatic Identification System. This directory currently holds
a single Matplotlib-generated SVG that illustrates TDMA channel saturation: how
slot occupancy, Class A collisions, and Class B carrier-sense (CS) deferrals
change as the number of stations in a cell grows.

The figure is the rendered output of the teaching simulator in
`code/tdma/sotdma_sim.py` (named in the plot title); it is a derived artifact,
not hand-drawn.

## Files
| File | Summary |
|---|---|
| `saturation.svg` | Matplotlib v3.11.2 line chart (401×257 pt) titled "Teaching simulator: Class B starves first (code/tdma/sotdma_sim.py)". X axis: "Class A stations in the cell (10 s interval) + 40 Class B (30 s)", ticks 100–700; Y axis: "fraction", 0.0–0.8. Three series sampled at 50, 100, 200, …, 700 Class A stations: "slot occupancy" (blue circles, rising roughly linearly then flattening toward ~0.8), "Class A collision rate" (orange squares, ~0 until ~300 stations then rising to ~0.4), and "Class B CS deferral rate" (green triangles, ~0 until ~200 stations then rising steeply to ~0.7). |

## Notes for agents
- The SVG is generated by Matplotlib (metadata date 2026-10-04); do not hand-edit it. Regenerate it by rerunning the simulator at `code/tdma/sotdma_sim.py` rather than modifying paths/text in the SVG directly.
- The chart's message, as stated in its title, is that Class B (CS) stations begin deferring well before Class A stations start colliding — i.e., Class B "starves first" as a cell saturates.
- The x-axis scenario fixes 40 Class B stations at a 30 s reporting interval and sweeps the number of Class A stations (10 s interval).
- Keep the filename `saturation.svg` stable; chapter text presumably references it by this name.
- No subdirectories, data files, or scripts live here; all source logic is in `code/tdma/`.
