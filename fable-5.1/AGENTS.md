# `/` (repository root)

This is the root of **The AIS Handbook**, an open, citable handbook on the
maritime Automatic Identification System — "from 'what is that triangle on my
chartplotter' to the bit timing of a GMSK burst, and from the sinking of the
Titanic to VDES." The book is 69 Markdown chapters in ten parts plus ten
appendices, each paired with a `.bibtex` file, backed by per-topic research
dossiers, runnable Python companion code, synthetic sample data, and generated
SVG figures. Prose is CC-BY-4.0, code is Apache-2.0 (see `LICENSE`).

The root holds the governing documents (plan, task backlog, style guide, table
of contents, contributing rules), the mdBook navigation file (`SUMMARY.md`),
the aggregate bibliography, and the Python test/dependency configuration. All
content lives in the six subdirectories below; every one of them has its own
`AGENTS.md` with file-level detail, which you should read before editing there.

## Subdirectories

| Directory | Summary |
|---|---|
| [`appendices/`](appendices/AGENTS.md) | Ten table-driven back-matter appendices A–J (timeline, standards register, message bit layouts, code tables, software/hardware/dataset/organization catalogs, glossary, code cookbook), each as `appendix-X-slug.md` + `.bibtex`. UTF-8 with CRLF line endings. |
| [`chapters/`](chapters/AGENTS.md) | The 69 chapters (`chNN-slug.md` + `chNN-slug.bibtex`) in Parts I–X, all following the fixed template in `STYLE_GUIDE.md` (numbered sections, then `Then & now` … `References`). Hundreds of relative cross-links between chapters, appendices, figures and `code/`. |
| [`code/`](code/AGENTS.md) | Runnable companion scripts (no packages; `sys.path.insert` imports) under `analytics/`, `decode/`, `figures/`, `rf/`, `security/`, `tdma/`, `viz/`, plus `tests/test_code.py` (13 pytest smoke tests). Run from the repo root with `pytest -q code`. |
| [`data/`](data/AGENTS.md) | Only `samples/`: a synthetic one-hour harbour NMEA stream with TAG blocks, its ground-truth CSV, and a mandatory `PROVENANCE.md`. Generated by `code/analytics/make_samples.py`; contains deliberate defects (MMSI `0`, `1193046`). |
| [`figures/`](figures/AGENTS.md) | `figures/chNN/*.svg` for ten chapters, all Matplotlib exports of `code/figures/make_figures.py`, plus `LICENSES.md` (CC-BY-4.0 statement and register for any imported figure). Never hand-edit the SVGs. |
| [`research/`](research/AGENTS.md) | 31 prose-only research dossiers `r-*.md` (standards, law, protocol, radio, hardware, history, software, security), each with sourced facts, confidence levels and `(verify)` markers, written before the chapters and mapped to the chapters they feed. |

## Notes for agents

- **Read the governing docs before writing prose.** `STYLE_GUIDE.md` is the
  authoritative template (heading order, boxes, units, citation style);
  `PLAN.md` §4 / `TABLE_OF_CONTENTS.md` define each chapter's scope;
  `CONTRIBUTING.md` and PLAN §1 state the honesty rules: never invent
  citations, DOIs, court cases, patents, CVE ids, statistics or model numbers;
  mark unconfirmed facts `(verify)`; cite accidents only to the official
  investigation report; security content is detection/defence-only with no
  transmit instructions or code.
- **Referenced tooling is not in this checkout.** `README.md`,
  `CONTRIBUTING.md`, `STYLE_GUIDE.md` and `PLAN.md` refer to `tools/`
  (`check_book.py`, `check_xrefs.py`, `check_citations.py`,
  `build_bibliography.py`, `make_stubs.py`, `generate_reviews.py`),
  `manifest.json`, `book.toml`, `CHANGELOG.md`, `CITATION.cff` and
  `CODE_OF_CONDUCT.md`. None of these exist here. Treat the style guide's
  template as the practical specification, use `SUMMARY.md` as the de-facto
  manifest of slugs/titles, and do not claim to have run the missing checkers.
  `BIBLIOGRAPHY.bib` says it is generated; without the generator, keep it in
  sync with the per-document `.bibtex` files by hand if you touch citations.
- **TASKS.md is aspirational in places.** Phase 1 lists dossiers (e.g.
  `r-shore-collection.md`, `r-security-threats.md`, `r-blender.md`,
  `r-incidents.md`, `r-mobile.md`) that are ticked but are not present in
  `research/` (31 dossiers exist; see `research/AGENTS.md`). Likewise
  Phase 2's figure list exceeds the eleven SVGs actually generated. Verify on
  disk rather than trusting a checkbox.
- **Everything is paired.** Each chapter/appendix `.md` has a `.bibtex` twin;
  renaming a slug breaks hundreds of relative links (`chapters/chNN-slug.md`,
  `../appendices/appendix-X-slug.md`, `../figures/chNN/name.svg`,
  `../code/...`) across chapters, appendices, `SUMMARY.md`,
  `TABLE_OF_CONTENTS.md` and the code docstrings. Search before renaming.
- **Running code and tests:** work from the repository root; install
  `requirements.txt`; run `pytest -q code` (or bare `pytest`, via
  `pytest.ini`). Scripts default to `data/samples/` inputs and resolve the
  repo root from their own path. Regenerating samples
  (`code/analytics/make_samples.py`) or figures (`code/figures/make_figures.py`)
  overwrites files under `data/samples/` and `figures/` and may invalidate
  test assertions and the quoted outputs in `appendices/appendix-i-cookbook.md`.
- **Chapter ↔ dossier ↔ code coupling.** When changing a fact, check the
  relevant `research/r-*.md` dossier, the chapter(s) it feeds, any appendix
  table that repeats it, and constants baked into `code/` and `figures/`
  (e.g. 161.975/162.025 MHz, 2,250 slots/min, 256-bit slots, 12.5 W / −107 dBm,
  the 4.12·(√h₁+√h₂) km radio horizon). Numbers should not disagree across
  files.
- **Conventions:** `(verify)` marks an unconfirmed fact (none may remain at
  milestone M4); `⟨H⟩` tags timeline items from the external
  `schwehr/gis-history` repo, `⟨+⟩` items added for this book; fast-moving
  facts carry "as of <Month YYYY>"; SI units first, nmi/kn where mariners use
  them, MHz, W/dBm, dBi, GT.
- **Line endings differ by directory:** root files and `chapters/` are UTF-8
  with LF; `appendices/` files are CRLF. Preserve whatever the file already
  uses to avoid whole-file diffs. Chapters and appendices use very long
  paragraph-per-line lines; prefer targeted edits over rewrites.
- **Licensing when adding material:** prose/figures/tables → CC-BY-4.0; code →
  Apache-2.0; new data files need a provenance entry
  (`data/samples/PROVENANCE.md` pattern); imported figures must be registered
  in `figures/LICENSES.md`.
