# `data/`

Top-level data directory for The AIS Handbook — an open, citable handbook on
the maritime Automatic Identification System. It holds the datasets that ship
with the book and are used by its worked examples and by the decoder/analytics
code under `code/`. At present the directory contains no files of its own;
all content lives in the single `samples/` subdirectory.

The data here is intentionally small, synthetic, and CC0-licensed so it can be
redistributed with the book without licensing or privacy concerns, and every
data file must be accounted for in a provenance manifest.

## Subdirectories

| Directory | Summary |
|---|---|
| [`samples/`](samples/AGENTS.md) | Synthetic sample datasets generated by `code/analytics/make_samples.py`: one hour of simulated harbour traffic as raw `!AIVDM` NMEA with TAG blocks (`synthetic_harbor.nmea`), a matching ground-truth CSV (`synthetic_harbor_truth.csv`), and a mandatory `PROVENANCE.md` manifest listing each file's source and licence. |

## Notes for agents

- There are no files directly in `data/`; read `samples/AGENTS.md` before
  touching anything below here.
- Data files in `samples/` are **generated**, not hand-written. Change
  `code/analytics/make_samples.py` and re-run it rather than editing the
  `.nmea`/`.csv` outputs, and keep the paired files in sync.
- Any new data file (in `samples/` or a new subdirectory) needs a provenance
  entry (source, licence, date/notes) following the `samples/PROVENANCE.md`
  pattern. Prefer synthetic or clearly redistributable data; the book is
  openly licensed.
- The sample NMEA stream contains deliberate defects (MMSI `0`, default MMSI
  `1193046`) that validators are expected to flag — do not "fix" them.
- If you add a new subdirectory, give it its own `AGENTS.md` and add a row to
  the Subdirectories table above.
