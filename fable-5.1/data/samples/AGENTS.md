# `data/samples/`

Small, redistributable sample datasets used by The AIS Handbook — an open,
citable handbook on the maritime Automatic Identification System. The files
here are *synthetic*: they are generated by `code/analytics/make_samples.py`
(using the pyais encoder) for fictional vessels, released under CC0, so they
can be shipped with the book, used in worked examples, and exercised by
decoder/analytics code without any licensing or privacy concerns.

The directory holds one hour of simulated harbour traffic as raw NMEA
(`!AIVDM` sentences with TAG blocks) plus a matching ground-truth CSV, so
decoders and analytics can be checked against known inputs. `PROVENANCE.md`
is the mandatory manifest of every data file's source, licence, and notes.

## Files

| File | Summary |
|---|---|
| `PROVENANCE.md` | Provenance table listing each sample file with source, licence (CC0), and notes. States the rule that every file in this directory must appear here. |
| `synthetic_harbor.nmea` | 2019 lines of `!AIVDM` sentences, each prefixed with an NMEA 4.x TAG block (`\s:SYNTH01,c:<unix-seconds>*hh\`). Covers one hour (c=1768478400 → 1768482000, i.e. 2026‑01‑15 12:00–13:00 UTC) and mixes message types including Class A position reports (type 1), static/voyage data (type 5, two-fragment multipart), Class B position reports (type 18), Class B static (type 24 parts A/B), base-station reports (type 4), and AtoN reports (type 21). Contains deliberate defects: a segment with MMSI 0 and a vessel using the default MMSI 1193046. |
| `synthetic_harbor_truth.csv` | Ground truth for each generated position report: 1802 data rows plus header `mmsi,time,lat,lon,sog,cog,heading,class`. Times are ISO‑8601 with `+00:00`; positions are near 42.1–42.45°N, 70.3–70.93°W; `heading` is 511 (not available) for Class B rows; `class` is `A` or `B`. |

## Notes for agents

- **Do not hand-edit the data files.** Both `.nmea` and `.csv` are regenerated
  by `code/analytics/make_samples.py`; change the generator and re-run it
  instead. Keep the two files in sync (they were produced together).
- **Any new file added here must get a row in `PROVENANCE.md`** with source,
  licence, and date/notes. This is a stated requirement of the directory.
- **Defects are intentional.** The NMEA stream includes a run of reports with
  MMSI `0` (30 rows in the truth CSV) and a vessel on the default MMSI
  `1193046` (120 rows). Decoders and validators are expected to flag these;
  do not "fix" them.
- MMSIs present in the truth CSV and their row counts: 338999702, 316999704,
  244999703 (360 each), 366999701 (331), 338123456 (121), 338654321 (120),
  1193046 (120), 0 (30). Class A vessels report every ~10 s; Class B every
  ~30 s.
- TAG blocks use the source id `SYNTH01` and a `c:` field giving the receive
  time in Unix seconds; the `c:` value is the link between an NMEA line and
  the `time` column in the CSV.
- Type 5 messages are split across two `!AIVDM,2,1,0,B,...` /
  `!AIVDM,2,2,0,B,...` fragments that share the same TAG block; a decoder must
  reassemble multipart messages to read them.
- The CSV uses CRLF (`\r\n`) line endings; `wc -l` reports 1803 lines
  (1 header + 1802 rows). The NMEA file uses LF.
- Longitudes are negative (western hemisphere) and `heading` of `511` means
  "not available" per the AIS spec, as used for all Class B rows.
