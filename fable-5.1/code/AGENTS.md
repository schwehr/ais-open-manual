# `code/`

Runnable companion code for "The AIS Handbook", an open, citable handbook on
the maritime Automatic Identification System. Everything here exists so that
numbers, figures and worked examples quoted in the book text can be reproduced
by readers: decoding NMEA/TAG-block input, cleaning and analysing tracks,
estimating receiver coverage, computing 162 MHz link budgets, synthesising a
GMSK burst, simulating the SOTDMA/CSTDMA slot map, running spoofing-triage
checks, regenerating the handbook's SVG figures, and building headless Blender
visualisations. Docstrings in the individual scripts cite the chapters they
support.

The directory contains no files of its own, only subdirectories. The scripts
are plain Python modules (no package `__init__.py` files) that find each other
via `sys.path.insert` on relative paths, and almost all of them operate on the
repository's synthetic sample data in `data/samples/`
(`synthetic_harbor.nmea` and `synthetic_harbor_truth.csv`, generated by
`analytics/make_samples.py`). A single pytest module in `tests/` smoke-tests
the whole tree.

## Subdirectories
| Directory | Summary |
|---|---|
| [`analytics/`](analytics/AGENTS.md) | Data-processing examples: synthetic sample generator (`make_samples.py`), NMEA → pandas/MovingPandas cleaning and trajectory pipeline, empirical receiver coverage estimation, and a DuckDB coverage-normalised density map. Provides `decode_file`, `haversine_nmi` and `nominal_interval_s` used by other directories. |
| [`decode/`](decode/AGENTS.md) | Wire-format helpers: an NMEA 4.10 TAG block parser (`tagblock.py`, used by `analytics/`) and a script that cross-checks pyais, libais and gpsdecode against the same NMEA file. |
| [`figures/`](figures/AGENTS.md) | `make_figures.py`, a Matplotlib script that regenerates eleven SVG figures into the repo-level `figures/chNN/` directories and rewrites `figures/LICENSES.md`, importing formulas from `rf/linkbudget.py` and the simulator from `tdma/sotdma_sim.py`. |
| [`rf/`](rf/AGENTS.md) | Physical-layer tools: NumPy-only GMSK burst synthesiser/demodulator (file output only, never a transmitter), 162 MHz radio-horizon and link-budget helpers (`linkbudget.py`), and an empirical-vs-predicted propagation comparison that depends on `analytics/`. |
| [`security/`](security/AGENTS.md) | `kinematic_checks.py`: per-MMSI plausibility flags (implied speed, SOG mismatch, turn rate, teleports, range from receiver, invalid MMSI) summed into a triage score. Built on `analytics/` decoding. |
| [`tdma/`](tdma/AGENTS.md) | `sotdma_sim.py`, a stdlib-only teaching simulator of one 2250-slot AIS channel with SOTDMA Class A, carrier-sense Class B, optional jammer and hidden-terminal model; deterministic via `run(..., seed=)`. |
| [`tests/`](tests/AGENTS.md) | `test_code.py`, 13 pytest smoke tests that import the library-style modules and run the remaining scripts via `subprocess` against the sample data. |
| [`viz/`](viz/AGENTS.md) | Headless Blender (`bpy`) scripts: an animation of vessel tracks from a CSV and a receiver-horizon vs. satellite-footprint scene. Both run (and print a summary) under plain Python when `bpy` is unavailable. |

## Notes for agents
- **Always run from the repository root.** Scripts resolve the repo root as
  `parents[2]` of their own path and default to `data/samples/...` inputs;
  tests are run with `pytest -q code`.
- **Cross-directory import graph (via `sys.path.insert`, no packages):**
  - `analytics/moving_pandas_pipeline.py` → `decode/tagblock.py`
  - `analytics/coverage_estimate.py`, `analytics/duckdb_density.py` → `moving_pandas_pipeline.py`
  - `rf/propagation_compare.py` → `rf/linkbudget.py`, `analytics/moving_pandas_pipeline.py`, `analytics/coverage_estimate.py`
  - `security/kinematic_checks.py` → `analytics/moving_pandas_pipeline.py`, `analytics/coverage_estimate.py`
  - `figures/make_figures.py` → `rf/linkbudget.py`, `tdma/sotdma_sim.py`
  - `tests/test_code.py` → `decode/tagblock`, `analytics/moving_pandas_pipeline`, `rf/linkbudget`, `tdma/sotdma_sim` (imports) plus the other scripts via subprocess.
  Renaming or moving a module, or changing function names such as
  `parse_line`, `format_tag`, `decode_file`, `clean`, `trajectories`,
  `haversine_nmi`, `nominal_interval_s`, `fspl_db`, `two_ray_db`,
  `radio_horizon_km`, `run`, or the decoded DataFrame columns
  (`type`, `mmsi`, `lat`, `lon`, `t`, `sog`, `cog`, `status`), breaks
  downstream directories and the tests.
- **Shared constants to keep consistent across directories:** receiver at
  `42.36, -70.95` (30 m; also the base station MMSI 3669712) passed as
  `--rx`; placeholder/invalid MMSIs `0` and `1193046` (also 123456789,
  111111111, 999999999 in `clean()`); the soft-coverage model (p = 1 inside
  15 nmi, linear to 0 at 35 nmi) mirrored in `analytics/make_samples.py` and
  the SQL of `analytics/duckdb_density.py`; the 4.12·(√h₁+√h₂) km radio
  horizon used in `rf/linkbudget.py`, `figures/`, and `viz/`; the −107 dBm
  sensitivity in `rf/linkbudget.py`; the "auto" propagation rule
  `max(FSPL, two-ray)` applied in both `rf/linkbudget.py` and
  `rf/propagation_compare.py`.
- **Sample data coupling:** `tests/test_code.py` asserts on properties of
  `data/samples/synthetic_harbor.nmea` (>1900 messages, types 1/4/5/18/21/24,
  six vessels after cleaning, MMSI 1193046 flagged) and on exact stdout
  substrings from the scripts. Regenerating the samples with
  `analytics/make_samples.py` (seeded with 1371) or changing printed output
  requires revisiting those assertions.
- **Chapter references** are hard-coded in docstrings and in
  `figures/make_figures.py` `save()` calls (output goes to `figures/chNN/`);
  update them if chapters are renumbered.
- **Dependencies:** `tdma/` is stdlib-only; `rf/gmsk_demo.py` and
  `rf/linkbudget.py` need only NumPy; `decode/` needs `pyais` (libais and
  gpsdecode optional); `analytics/`, `security/`, and `rf/propagation_compare.py`
  need `pyais`, `pandas`, `numpy`, plus `geopandas`/`movingpandas`/`duckdb`
  for the analytics scripts; `figures/` needs `matplotlib`; `viz/` needs
  Blender for real output but imports without it. Install the handbook's
  Python environment before running tests.
- **Safety/legal:** `rf/gmsk_demo.py` writes baseband samples to a file only
  and must never gain an SDR transmit path; `tdma/sotdma_sim.py` is pure slot
  bookkeeping with no transmit code. Keep that separation (RF/bit-level
  behaviour belongs in `rf/`, slot logic in `tdma/`).
- **Destructive side effects to be aware of:** `figures/make_figures.py`
  overwrites `figures/LICENSES.md`; `viz/` scripts delete every object in the
  current Blender file before building; `analytics/make_samples.py`
  overwrites the files in `data/samples/`.
- Only `tests/` contains tests; the other directories are verified by running
  their scripts end to end (see each subdirectory's AGENTS.md for exact
  commands).
